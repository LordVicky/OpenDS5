# Make PipeWire Topology Changes Evidence-Driven

OpenDS5 will not change its public WirePlumber channel presentation or add a hidden fallback topology speculatively. The existing PipeWire route remains part of the non-GE-Proton compatibility surface, while the GE-Proton native path is validated first through its direct ALSA hardware contract; topology changes require runtime evidence from a real wired DualSense, vDS, or the actual GE-Proton fallback behavior.
