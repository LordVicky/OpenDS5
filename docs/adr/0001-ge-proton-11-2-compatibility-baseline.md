# GE-Proton 11-2 Compatibility Baseline

OpenDS5's native DualSense haptics work will target GE-Proton 11-2 as the minimum supported GE-Proton behavior, while checking newer upstream patches and preserving compatibility for users who do not run GE-Proton. Production changes must follow a completed and reviewed Phase 1 analysis; hardware-dependent conclusions must remain explicitly identified as manual validation requirements. This scope keeps the implementation protocol-faithful instead of coupling it to one Proton release or replacing general controller behavior with GE-specific hacks.
